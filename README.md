### Olá, eu sou o Sávio 👋

Desenvolvedor full stack, de Rio de Janeiro. Gosto de transformar dados públicos em ferramentas úteis para as pessoas.

**Destaque: [Ramal — trens do Rio](https://ramal-l9ye.onrender.com/)**
Aplicativo web para consultar próximos trens, rotas, horários oficiais, mapa e avisos dos trens da região metropolitana do Rio de Janeiro.
- Horários e estações a partir de páginas públicas da operadora
- Planejador de viagem com baldeações e passo a passo
- Mapa com posição estimada dos trens e a sua localização
- Funciona no celular e pode ser instalado como app, sem loja
- Stack: Node.js, JavaScript, HTML/CSS, SQLite, Leaflet, Docker, GitHub Actions
